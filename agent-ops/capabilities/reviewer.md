# Capability: reviewer

**When:** `role: reviewer` on `[PROPOSAL]` or `[DECISION]` issues.

## Do

- Comment on VK issue: `APPROVE`, `REJECT`, or `NEEDS_INFO` with rationale.
- For DECISION: record outcome in issue body when resolved.
- hcom NOTIFY room when review is requested.

## Do not

- Implement code changes.
- Use hcom DISCUSS before 2 VK comment rounds (unless escalated to BLOCKED).

## Multi-reviewer

Claude may veto; implementer agent may comment. No complex vote rules in Phase 1.
